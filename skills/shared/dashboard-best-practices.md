# 仪表板最佳实践

## 专业报告工作流

1. **结构化数据** → Excel 表格
2. **格式化值** → 按数据类型的数字格式
3. **添加视觉效果** → 明确定位的图表
4. **验证布局** → 确认无重叠
5. **保存并关闭**

## 专业报告工作流（详细版）

每个报告或仪表板应遵循此顺序：

```
1. 结构化数据 → Excel 表格（永远不要用普通范围）
2. 格式化值 → 按数据类型的数字格式
3. 添加视觉效果 → 明确定位的图表
4. 验证布局 → 截图确认无重叠
5. 保存并关闭 → 持久化更改
```

### 步骤 1：将数据结构化为 Excel 表格

**始终为表格数据使用 Excel 表格：**

```
range(set-values, rangeAddress='A1', values=[[headers + data]])
table(create, tableName='SalesData', rangeAddress='A1:D20')
```

**为什么表格重要：**
- 每列自动筛选
- 条纹行提高可读性
- 公式中的结构化引用
- 数据模型 / DAX / 透视表必需
- 添加新行时自动扩展

### 步骤 2：按数据类型格式化值

**设置值后应用数字格式 - 之前不要：**

| 数据类型 | 格式代码 | 结果 |
|----------|----------|------|
| 货币 (USD) | `$#,##0.00` | $1,234.56 |
| 货币 (EUR) | `€#,##0.00` | €1,234.56 |
| 百分比 | `0.0%` | 12.3% |
| 日期 | `yyyy-mm-dd` | 2025-01-22 |
| 数字（千位） | `#,##0` | 1,235 |
| 会计 | `_($* #,##0.00_)` | $ 1,234.56 |

**始终使用美国格式代码** - Excel 自动翻译为用户区域设置。

### 步骤 3：无重叠定位图表

**图表具有自动碰撞检测和三种定位模式：**

#### 单个图表（自动定位或 targetRange）
```
# 选项 A：targetRange（明确单元格放置）
chart(create-from-range, sourceRange='A1:D20', targetRange='F2:K15')

# 选项 B：省略位置 - 自动放置在内容下方
chart(create-from-range, sourceRange='A1:D20', chartType='Line')
```

#### 多个图表（仪表板）- 始终使用 targetRange
```
在数据下方以网格模式放置：

图表 1: targetRange='A22:F35'    （左上）
图表 2: targetRange='G22:L35'    （右上）
图表 3: targetRange='A37:F50'    （左下）
图表 4: targetRange='G37:L50'    （右下）
```

**规则：**
- **多图表布局使用 targetRange** - 自动定位垂直堆叠
- 图表间留 1-2 行/列间距
- 图表放在数据区域**下方**，而非旁边
- 保持图表大小一致
- **始终检查结果消息**中的重叠警告

### 步骤 4：截图验证

**创建图表或复杂布局后始终截图：**

```
screenshot(capture-sheet)
→ 确认：无重叠、专业间距、可读标签
→ 如发现问题：chart(fit-to-range) 重新定位，然后再次截图
```

### 格式化清单

- [ ] 数据在 Excel 表格中（非普通范围）
- [ ] 已应用数字格式（货币、日期、百分比）
- [ ] 列宽适合内容
- [ ] 图表标题描述性强
- [ ] 图表轴标签已格式化
- [ ] 无图表与数据或其他图表重叠
- [ ] 仪表板中图表大小一致
- [ ] 已截图验证最终布局
