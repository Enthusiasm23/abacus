# 中文错误消息规范

## 设计原则

1. 使用中文描述错误
2. 提供修复建议
3. 包含具体上下文

## 错误消息模板

### 参数错误
```
参数错误：{参数名} 无效
期望：{期望值或格式}
实际：{实际值}
建议：{修复建议}
```

**示例**：
```
参数错误：range 无效
期望：A1:D10 格式的范围
实际：A1-D10
建议：使用冒号分隔，如 A1:D10
```

### 公式错误
```
公式错误：{错误描述}
位置：{单元格}
公式：{公式内容}
建议：{修复建议}
```

**示例**：
```
公式错误：公式必须以 = 开头
位置：B10
公式：SUM(A1:A9)
建议：改为 =SUM(A1:A9)
```

### 文件错误
```
文件错误：{错误描述}
路径：{文件路径}
建议：{修复建议}
```

**示例**：
```
文件错误：文件不存在
路径：C:\data\report.xlsx
建议：检查文件路径是否正确
```

### 工作表错误
```
工作表错误：{错误描述}
工作表：{工作表名称}
建议：{修复建议}
```

**示例**：
```
工作表错误：工作表不存在
工作表：Sheet1
建议：检查工作表名称是否正确，或先创建该工作表
```

## 成功消息模板

### 操作成功
```
操作成功！
操作：{操作描述}
结果：{结果详情}
```

**示例**：
```
操作成功！
操作：合并单元格
结果：A1:D1 已合并
```

### 批量操作成功
```
批量操作成功！
操作：{操作描述}
总数：{总数}
成功：{成功数}
失败：{失败数}
```

**示例**：
```
批量操作成功！
操作：写入数据
总数：100
成功：100
失败：0
```
