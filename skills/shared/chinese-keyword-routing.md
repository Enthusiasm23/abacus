## 场景示例

### 示例1：查找数据
**用户说**：「帮我写个公式，根据产品名称查价格」

**处理步骤**：
1. 识别关键词：查价格 → VLOOKUP
2. 分析数据结构：A列=产品名称，B列=价格
3. 生成公式：`=VLOOKUP(D2,$A$2:$B$100,2,FALSE)`
4. 解释：在A列查找D2的值，返回B列对应的价格
5. 写入单元格

### 示例2：条件判断
**用户说**：「如果销售额大于10000就显示达标，否则显示未达标」

**处理步骤**：
1. 识别关键词：如果...就 → IF
2. 分析条件：销售额 > 10000
3. 生成公式：`=IF(B2>10000,"达标","未达标")`
4. 写入单元格

### 示例3：数据清洗
**用户说**：「把这个表格的空行删掉」

**处理步骤**：
1. 识别关键词：空行 → remove_empty_rows
2. 扫描数据范围
3. 删除空行
4. 返回删除的行数
