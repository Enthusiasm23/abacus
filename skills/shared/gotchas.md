# 已知限制和陷阱

## 透视表格式丢失

**问题：** 透视表刷新后格式可能丢失

**解决方案：**
- 使用透视表内置样式（不手动格式化）
- 刷新前保存格式配置
- 刷新后重新应用格式

## 隐藏对象

**问题：** 隐藏的工作表/行/列可能影响操作

**解决方案：**
- 操作前检查对象可见性
- 使用 `skip_hidden` 参数
- 明确处理隐藏对象

## 超时问题

**问题：** 大数据集操作可能超时

**解决方案：**
- 分批处理大数据集
- 使用手动计算模式
- 增加超时设置

## COM 对象泄漏

**问题：** COM 对象未正确释放

**解决方案：**
- 使用 try/finally 确保释放
- 不要在循环中创建 COM 对象
- 使用 with 语句管理资源

## 公式计算顺序

**问题：** 公式依赖关系可能导致计算错误

**解决方案：**
- 使用手动计算模式
- 按依赖顺序写入公式
- 最后触发一次完整计算

## 数据验证限制

**问题：** 数据验证规则可能被绕过

**解决方案：**
- 使用程序化验证（不只是 Excel 验证）
- 在写入前验证数据
- 使用条件格式标记无效数据

## 跨工作簿引用

**问题：** 跨工作簿引用可能断裂

**解决方案：**
- 使用绝对路径
- 确保源工作簿已打开
- 使用数据模型替代跨工作簿引用

## 合并单元格陷阱

**问题：** 合并单元格可能导致排序/筛选失败

**解决方案：**
- 避免在数据区域使用合并单元格
- 使用跨列居中替代合并
- 操作前取消合并

## 透视表自定义格式不持久

用户格式（颜色、粗体、边框等）在刷新或工作簿重新计算时会被清除。

**原因：** 透视表由 Excel 的布局引擎生成，每次刷新时重新应用默认格式。

**解决方案：** 使用 `pivottable(action: 'set-style')` 应用表级样式。样式在刷新间持久。避免对透视表单元格使用 `range_format()`。

## 数据模型隐藏对象对 COM 不可见

在 Power Pivot 中标记为**"对客户端工具隐藏"**的列、关系和度量无法通过 Excel COM API 检测、列出或访问。无解决方案。

**原因：** Microsoft 故意对自动化隐藏这些对象以防止破坏依赖计算。

**这意味着：**
- 无法枚举数据模型表中的所有列（隐藏的不显示）
- 无法检测标记为隐藏的关系
- 无法列出所有度量（隐藏的度量不可见）
- 如果预期对象未出现在 `datamodel` 列表中，请检查 Power Pivot UI

## 大型 Power Query 刷新超时

`powerquery(action: 'refresh')` 的默认超时是 **5 分钟**。查询大型数据集的 Power Query 操作经常超过此限制。

**症状：** 操作似乎成功但数据未加载，或 5 分钟后超时错误。

**修复：** 打开会话时增加超时：

```json
{
  "action": "open",
  "filePath": "C:\\path\\to\\workbook.xlsx",
  "timeoutSeconds": 900
}
```

## 会话并发需要 STA 线程

非 STA（单线程单元）线程上的多个 Excel 会话在初始化期间可能死锁。COM 引擎要求所有会话在同一线程池上运行。

**解决方案：** 如果实现自定义会话管理，确保所有 Excel COM 调用在单个专用 STA 线程上发生。

## 连接字符串区分大小写

OLEDB 和 ODBC 连接字符串要求参数键（Provider、Data Source、User ID、Password 等）精确区分大小写。Excel 在创建连接时**不**验证语法 - 失败出现在**刷新时**。

**修复：** 创建连接前始终验证连接字符串语法。

## 公式在计算完成前返回 0

使用 `range(action: 'set-formulas')` 写入公式时，它们不会自动计算。如果立即读取，会看到 0 或 #VALUE!。

**原因：** Excel 根据计算模式在后台或按需计算公式。

**修复：** 写入公式后，在读取值之前调用计算：

```
1. range(action: 'set-formulas', ...)     → 公式已写入，未计算
2. calculation_mode(action: 'calculate')  → 现在重新计算
3. range(action: 'get-values', ...)       → 读取计算结果
```

## 跨会话文件锁定

如果多个 Excel 会话打开同一工作簿，一个会话的操作可能锁定文件并在其他会话上超时（30 秒超时）。

**预防：** 每个文件只在一个会话中打开。

## Excel 可见/隐藏状态是会话全局的

调用 `window(action: 'show')` 或 `window(action: 'hide')` 会影响整个 Excel 应用程序，而不仅仅是当前会话。

## 特殊字符的范围地址

带空格、连字符或特殊字符的范围名称必须用单引号或反引号括起：

```
rangeAddress: 'Sales Data'      ← 正确（带空格）
rangeAddress: Sales Data        ← 错误（失败）
rangeAddress: `Sales Data`      ← 也正确（反引号）
```

## Power Query 的 DATE 转换

Power Query 返回日期时，它们作为 **OLE 日期数字**返回（例如 45300 代表 2024-01-01）。Excel 在单元格中自动处理转换，但如果在 Excel 外程序化处理这些值，需要解析：

```python
actual_date = datetime.fromordinal(int(ole_date_value) + 1)
```
