# 公式诊断指南

## 常见错误类型

| 错误 | 原因 | 解决方案 |
|------|------|----------|
| #REF! | 引用的单元格不存在 | 检查引用的单元格是否被删除 |
| #N/A | 查找值未找到 | 检查查找值是否存在 |
| #VALUE! | 参数类型不匹配 | 检查函数参数类型 |
| #NAME? | 函数名或范围名不存在 | 检查函数名拼写 |
| #DIV/0! | 除数为零 | 添加 IFERROR 或检查除数 |
| #NUM! | 数值超出范围 | 检查数值是否在有效范围内 |
| #NULL! | 区域引用不相交 | 检查区域引用是否正确 |

## 诊断步骤

1. 定位错误单元格
2. 检查公式语法
3. 验证引用单元格
4. 检查数据类型
5. 测试公式逻辑

## 常见问题

### VLOOKUP 返回 #N/A
- 检查查找值是否存在
- 检查查找范围是否正确
- 检查列号是否正确

### SUM 返回 #VALUE!
- 检查范围是否包含文本
- 检查是否有错误值

### IF 返回 #NAME?
- 检查函数名拼写
- 检查是否使用了中文括号
